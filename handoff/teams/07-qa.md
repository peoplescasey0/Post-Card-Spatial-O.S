# BRIEFING — 07 tests and QA

## Mission

Be the gate, not a phase. You own the thing that makes eight sections safe to
merge: a fast, honest, green suite on a clean machine.

## Start

**Today.** 285 tests pass in 27 seconds locally. Make that true somewhere that
isn't Casey's laptop.

## Owns

- `workspace-prototype/tests/` (26 files today)
- `.github/workflows/ci.yml`
- contract validation (the commented `contracts` job — yours to enable)
- `workspace-prototype/handoff/contracts/` validators

## First three tasks

1. Turn on CI. First green run on a clean runner is the single highest-value
   artifact this project can produce right now.
2. Add contract validation: fixtures that decode against `plane.v1.json`,
   `card-manifest.v1.json`, `telemetry.v1.json`. Fail the build on drift.
3. Audit for tests that assert source text instead of behavior
   (`native-hud-telemetry.test.mjs` greps for strings and will pass on broken
   code). Replace with behavioral assertions or mark them explicitly as smoke tests.

## Rules

- A test that needs a running QEMU must be skippable via env flag, or CI will flake.
- Never delete a failing test to go green. Quarantine it with a reason and an issue.
- Every fix in another section arrives with a test. No exceptions.

## Definition of done

- Public CI badge that is green.
- Contract drift breaks the build.
- Test suite stays under 2 minutes so people actually run it.

## Do not touch

Source files outside `tests/` and CI. You write tests, not features.
